Technologies Used

This project uses web development technologies to provide a simple news browsing experience.

Frontend

* HTML – Page structure
* CSS – Styling and layout
* JavaScript – Interactive functionality

Development Tools

* Git – Version control
* GitHub – Source code hosting
* Visual Studio Code – Code editor

Future Technology Improvements

* React for reusable UI components
* API integration for real-time news
* Responsive UI improvements

Goal

To build a user-friendly news application while improving practical frontend development skills.
